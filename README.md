# ESP32-S3 SuperMini NES 掌机 —— 接线清单（最终版）

> 本文以 `firmware/hw_config.h` 的实际定义为准。改引脚时先改代码再改本文。

## 板子引脚分布（实物丝印）

**边缘（castellated，2.54mm 间距，好焊）**

```
  侧 A（9 个）              侧 B（9 个）
  ┌────────────────┐      ┌────────────────┐
  │  TX            │      │  5V            │
  │  RX            │      │  GND           │
  │  1             │      │  3V3           │
  │  2             │      │  13            │
  │  3             │      │  12            │
  │  4             │      │  11            │
  │  5             │      │  10            │
  │  6             │      │  9             │
  │  7             │      │  8             │
  └────────────────┘      └────────────────┘
```

**底部裸露焊盘（1.27mm 间距，难焊，建议用 0.1mm² 飞线 + 热熔胶固定）**

```
     左列（上→下）        右列（上→下）
        34                  38
        33                  37
        21                  36
        19  ← 禁碰(USB D-)  35
        17  ← 已损坏        45
        16  ← START         42  ← SELECT
        15                  41
        14  ← B             40
                            39  ← 已损坏
        中间：48(接RGB LED) 47  46(strapping)
```

## 一、屏幕 ST7789（240×240，8 个脚）

| 屏幕引脚 | 接到哪里 | 板子上的位置 |
|---|---|---|
| VCC | **3V3** | 侧 B |
| GND | **GND** | 侧 B |
| SCL (SCK) | **12** | 侧 B |
| SDA (MOSI) | **11** | 侧 B |
| RES (RST) | **9** | 侧 B |
| DC | **13** | 侧 B |
| CS | **10** | 侧 B |
| BLK | **3V3** | 侧 B（背光，可接 3.3V 常亮） |

> 屏幕只写不读，所以没有 MISO。

## 二、SD 卡模块（6 个脚，FAT32 格式）

| SD 模块引脚 | 接到哪里 | 说明 |
|---|---|---|
| VCC | **5V** | ⚠️ 模块带 AMS1117 稳压器时**必须接 5V**：接 3V3 时稳压器压差不够，卡实际只有 ~2.2V，会出现「命令能应答、读数据全 0」的怪现象 |
| GND | **GND** | |
| MISO | **8** | 只给 SD 卡用 |
| MOSI | **11** | **与屏幕共用同一根线** |
| SCK | **12** | **与屏幕共用同一根线** |
| CS | **7** | 独立片选 |

> SPI 总线共享：屏幕和 SD 卡并联在 11/12 两根线上，靠各自的 CS 分时访问。
> 没有稳压芯片的纯 3.3V 模块才接 3V3（先看模块上有没有那颗 3 脚稳压芯片）。
> ROM 文件名必须以 `.nes` 结尾，放根目录（FAT16/FAT32 格式）。

## 三、MAX98357A 功放（I2S）

| 模块引脚 | 接到哪里 | 说明 |
|---|---|---|
| VIN | **5V** | 5V 比 3.3V 声音大 |
| GND | **GND** | |
| LRC | **5** | 声道时钟 |
| BCLK | **6** | 位时钟 |
| DIN | **4** | 数据 |
| SD | 悬空 | 关断控制，悬空=常开 |
| GAIN | 悬空 | 悬空=9dB 增益 |
| OUT+ / OUT- | 小喇叭 | 4Ω 或 8Ω |

> 只接 3 根信号线，不需要 MCLK。

## 四、按键（8 个，全部一端接 GPIO、另一端接 GND）

| 按键 | GPIO | 丝印/位置 | 板子位置 |
|---|---|---|---|
| UP | **1** | `1` | 侧 A |
| DOWN | **2** | `2` | 侧 A |
| LEFT | **3** | `3` | 侧 A |
| RIGHT | **43** | **`TX`** | 侧 A |
| A | **44** | **`RX`** | 侧 A |
| B | **14** | `14` | **底部左列最下** |
| START | **16** | `16` | **底部左列** |
| SELECT | **42** | `42` | **底部右列** |

> 全部使用内部上拉（`INPUT_PULLUP`），按键另一端接 GND，按下为低电平。

## 五、电源汇总

| 电源 | 供给对象 |
|---|---|
| **3V3** | 屏幕 VCC、屏幕 BLK |
| **5V** | SD 卡模块 VCC（带稳压器时必须 5V）、MAX98357A 的 VIN |
| **GND** | 屏幕、SD 卡、功放、全部 8 个按键的另一端 |

> SuperMini 的 5V 是 USB 输入直通，3V3 来自板上 LDO。功放接 5V 时注意总电流别超过 USB 口的供电能力。

## 六、已损坏 / 禁止使用的引脚

| GPIO | 状态 | 说明 |
|---|---|---|
| **17** | **已损坏** | 原计划给 SELECT，焊接时损坏 |
| **39** | **已损坏** | 原计划给 SELECT，扯线时损坏 |
| 19 | **禁止使用** | USB D-，动它会断连 |
| 20 | 禁止使用 | USB D+ |
| 33,34,35,36,37,38 | 禁止使用 | PSRAM / 二次 flash 相关 |
| 45,46 | 禁止使用 | strapping（影响启动和 flash 电压） |
| 47 | 不建议 | 谨慎使用 |
| 48 | 不可用 | 板载 WS2812 RGB LED 占用 |
| 0,3 | 不建议 | strapping（boot 模式 / JTAG 选择） |

## 七、引脚占用一览（共 18 个 GPIO）

```
边缘 15 个（全用满）：
  侧 A: TX  RX  1  2  3  4  5  6  7      ← 9 个全是 GPIO
  侧 B: 13  12  11  10  9  8              ← 6 个 GPIO（另 3 个是电源）

底部 3 个：
  14（B）、16（START）、42（SELECT）
```

**边缘 15 个正好用满，一个不剩** —— 所以 3 个按键必须焊底部。

## 九、烧录

固件产物在 `firmware/build/`：

- `Dsn_nes_Emulator.ino.merged.bin` —— **4MB 整片镜像，烧到 0x0**
- 游戏 ROM 放 SD 卡**根目录**，`.nes` 格式，最多识别 64 个
- SD 卡必须 **FAT32** 格式

```powershell
esptool --chip esp32s3 -p COMx -b 921600 write-flash 0x0 .\Dsn_nes_Emulator.ino.merged.bin
```
